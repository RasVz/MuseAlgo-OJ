# 刷题 AI 教学助教

普通练习中打开题目详情页的「AI 助教」，即可描述问题。完整讲解与参考代码首次即可请求，没有提示级别或解锁条件。普通练习的 AC 提交也支持复盘与优化。

## 教学模式

| 模式 | 用途 |
|---|---|
| 读懂题目 | 详细解释目标、输入输出与数据范围，手推公开样例 |
| 给我提示 | 围绕切入点给简短提示，不直接展开核心修复或完整解法 |
| 检查思路 | 检查正确性和复杂度，寻找反例或修补方向 |
| 排查代码 | 简洁指出位置、原因、最小修改与验证例 |
| 完整讲解 | 推导、正确性依据、复杂度与完整参考实现 |

五个选项就是学生可见的全部模式，按钮始终显示在问题框上方。点击会把对应提示追加到现有问题末尾，不覆盖已输入内容，重复点击不会重复追加，也不会自动请求 AI；按钮同时记录对应 `helpMode`。自由提问始终可用；未选择模式时使用默认 `AUTO`，直接、简洁地回答当前问题。

解释知识点、构造反例和优化代码等需求直接在问题中描述即可。你在当轮问题中的明确要求优先，例如选择“给我提示”后说“现在直接告诉我怎么改”，助教应按当轮要求回答。提示模式不是输出过滤器，也没有分级解锁。

默认优先保留学生已有思路和实现，能局部修复就解释局部缺口。参考代码需运行、评测验证，未实测不保证 AC，自拟数据不是平台隐藏测试点。

## 代码与会话

- 每次发送读取当前编辑器代码和语言；阅读模式使用当前页保留的草稿，或最近保存的云端草稿及实际语言。其他标签页/设备未保存的内容不会自动同步。
- 正式题面、输入输出、公开样例、提示和时空限制由服务端校验题目读取权限后提供；不发送教师标准答案或隐藏测试点原文。
- 普通答疑按当前用户和题目隔离，历史保留最近十轮、24 小时有效；请求时还会按预算去掉过长的旧轮次。
- 关闭抽屉、切题或停止生成会取消请求；已收到片段标为未完成，未完成回复不作为完整回答写入服务端历史。
- 清空同时作用于服务端。若本题仍有请求处理，会提示稍后重试，不显示清空成功。
- 复盘分析指定历史提交。追问携带的前次分析仅作为用户提供的参考文字，过长时节选，不代表当前编辑器草稿。

## 默认诊断与临时样例

题目答疑默认结合当前代码和有效运行记录分析，无需打开额外开关。平台优先复用同一用户、题目、代码、语言与输入的短期运行回执；代码或输入改变后不复用旧结果。当前选中样例的输入可以作为分析材料；自测输出栏展示的实测结果不等同于正式评测结论。

模型能直接解释时不试跑；需要验证具体假设时可申请一个短输入，服务端取证后再回答。默认最多一轮取证、一个输入，最终回答轮不再开放工具。当前模型不支持工具、执行服务繁忙或验证超时会说明边界，继续依据已有材料回答。不会自动修改编辑器、运行整套隐藏评测或产生正式提交。

题面下方展示只读样例；进入编辑器后，自测面板负责选择、编辑和查看当前样例结果：

- 题面中的官方样例始终只读。自测中的官方样例输入禁止修改；自定义样例可编辑和删除，输入文本框为 4 行。
- 编辑器工具栏只保留一个「运行」按钮，位于「提交代码」左侧，用于运行当前选中的样例；运行期间该按钮原位变为「停止」。已有同版本结果可复用，不再提供「运行全部」。
- 输出框只读，仅展示当前代码最近一次运行的真实 stdout，不保存或比较期望输出。代码或输入变化后旧输出立即失效；输出被截断、编译错误、运行错误和执行服务故障分别提示。
- 运行结果不代表整题 AC；正式正确性仍以提交后的评测为准。
- 服务端确认输出差异或输入触发的运行异常后，反例自动去重加入本页；编译错误、判题服务内部故障和未经可信比较的 AI 猜测不会自动作为已验证反例。超长样例不能完整传送时不自动加入，保留分析说明。
- 临时样例只在当前页面内存中，刷新、离开或切题后清空，不写题目样例数据库和浏览器持久存储。运行服务短期回执保留 30 分钟，仅用于隔离与复用；它与本页样例列表不同。

学生可以查看今日剩余额度和诊断状态。模型判断是否需要取证仍需要真实模型验收；程序输出和错误文本属于不可信分析数据，不能改变系统规则。

## 参考题解与管理

「管理中心 → AI 管理 → 教学诊断与试跑」提供试跑次数、复用、错误/超时/服务异常、执行耗时、参考题解命中及已验证反例事件统计。AI 请求/token 与这些执行资源分开统计；按日资源统计保留 32 天，不存代码或样例正文。

管理员可以按题目 ID 查看题解是否连通，选择同题、公开、未删除且不属于私有班级的官方题解。未指定时自动选择可用官方题解；指定内容失效后显示缺失，不悄悄切换其他材料。普通用户帖子不会自动当成可信官方题解。没有题解时，助教仍可依据题面、代码与运行事实推导。

官方题解优先获得 8000 字符预算，过长保留头尾并标明节选，补充材料最多约 2000 字符。默认没有把教师私有标准答案或隐藏测试点注入提示词。

后台可设置每次提问验证输入数 0～2（默认 1）及整轮取证等待上限 2～30 秒（默认 12 秒）。0 表示暂停自动试跑，答疑仍可用。取证执行并发 2、等待队列 4；繁忙时返回未完成证据而不虚构结果。诊断输入和新建临时样例输入/期望各限 4096 字符，每页最多保留 30 个样例；历史官方样例手动试跑支持到 65535 字符，代码上限 16000 字符。

间接 AI 建议、学情解读、题面格式化同样记录可得用量；后台学生报告显式记录归属学生。缓存命中记录供应商消耗为 0；无归属用户的兼容调用保留资源指标并告警，不伪造用户流水。这些业务调用沿用自己的入口权限，学生提问配额口径保持 ASK/REVIEW。

## 比赛场景

比赛入口的题目详情页在阅读、编辑模式均不提供 AI，比赛提交也不提供 AI 复盘。后端拒绝携带比赛上下文的教学请求，并按数据库中的真实提交归属拦截复盘，包括赛后的比赛入口。

普通练习对有权查看的题目开放，不按参赛账号或题目关联比赛全局禁用。入口绕行和同题搜索不属于本功能的防作弊范围。教师命题工具保持独立。

## 接口与资源

| 接口 | 用途 |
|---|---|
| `POST /ai/ask/stream` | 答疑：problemId、studentQuestion、studentCode、language、可选 contestId 与 helpMode |
| `POST /ai/review` | 复盘：submissionId、可选 studentQuestion/previousAnswer/contestId 与 helpMode |
| `GET /ai/conversation?problemId=…` | 恢复当前用户本题历史 |
| `DELETE /ai/conversation?problemId=…` | 清空当前用户本题历史 |
| `GET /ai/quota` | 当前用户剩余额度、豁免状态及重置时间 |
| `POST /problem/run` | 当前代码试跑；可带 problemId，返回 runId、原始输出和错误详情 |
| `GET /admin/ai/diagnostics?days=…` | 管理员按日资源统计，1～30 天 |
| `GET/PUT /admin/ai/diagnostics/settings` | 管理员取证输入数及等待预算 |
| `GET/PUT /admin/ai/diagnostics/reference` | 管理员查看/指定公开官方题解 |
| `GET /problem/draft/latest?problemId=…` | 当前用户本题最近保存的草稿及语言 |

`helpMode`：AUTO、READ_PROBLEM、GET_HINT、CHECK_APPROACH、DEBUG_CODE、FULL_SOLUTION，缺省为 AUTO。回答方式和展开程度已并入单一模式，不再接收 `helpDirection`、`answerStyle` 或 `detailLevel`。旧请求中的题面和 hintLevel 不再作为权威上下文或解锁依据。

答疑可选传 runIds（最多 5 条回执）和 selectedSample（input、hasExpected、expectedOutput、note）；回执由服务端重新校验，不信任客户端自报的运行结果。

SSE 使用 message/done/app-error，另有 diagnostic-status（取证状态）和 counterexample（可靠反例）JSON 元事件，元事件不混进回答正文；收到 done 才视为完整回复。输入按字符预算控制，核心题面或代码过长时明确拒绝，检索资料允许节选并标记；字符预算不是精确 tokenizer。LEGACY/MANAGED 流式调用均实际传递配置的 max_tokens，达到上限返回 AI_OUTPUT_LIMIT，不作为完整回答保存。

手动试跑按用户每 60 秒最多 30 次；ASK/REVIEW 共用用户级限频：每 60 秒最多 12 次；同用户同题的答疑、恢复和清空使用互斥租约。沿用每日 token 配额，仅成功回复消耗学生额度。

流水区分 SUCCESS、FAIL、CANCELLED、QUOTA_REJECTED、CONTEST_BLOCKED。未发送上游请求时不虚构用量；已发送且无 usage 时按已发送输入/已接收输出估算，取消后的最终费用以供应商账单为准。多轮取证的输入、输出用量合并为一条问答记录；任一轮缺少 usage 时保留已知用量，并对该轮补估算及标记。

开放模板键为 tutor-open、review-open；旧 tutor/review 激活版本不会覆盖新流程。新模板不插入题面/代码，不使用位置格式化占位符。学生 `/ai/hint/level` 和教师 `/ai/teacher/hint/levels` 已退役；旧 Hint 数据保留历史含义，新请求不写解锁轨迹，旧比赛全局开关与缓存配置不再生效。

## 教学质量评审

使用真实模型分别评审以下案例：正确思路的小边界错误、不成立思路的反例、复杂度不足、完全无思路、明确只要提示、首轮请求完整解答。检查是否保留已有思路、准确定位、解释充分、遵循当轮要求。模型回答正确率与课堂学习效果不能以接口测试通过替代。
