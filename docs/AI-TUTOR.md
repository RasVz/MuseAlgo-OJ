# 刷题 AI 教学助教

普通练习中打开题目详情页的「AI 助教」，即可描述问题。完整讲解与参考代码首次即可请求，没有提示级别或解锁条件。普通练习的 AC 提交也支持复盘与优化。

## 帮助方向与表达偏好

| 方向 | 用途 |
|---|---|
| 读懂题目 | 理解目标、输入输出与数据范围，手推公开样例 |
| 找切入点 | 从题目特征建立观察，找到可继续推进的方法 |
| 检查我的思路 | 检查正确性和复杂度，寻找反例或修补方向 |
| 定位代码错误 | 指出位置、原因、最小修改与验证例 |
| 解释代码与知识点 | 理解变量、执行过程、语法和算法概念 |
| 构造样例与反例 | 自拟输入及预期输出，检验边界和思路漏洞 |
| 优化我的代码 | 分析瓶颈、复杂度和必要改动 |
| 完整题解与代码 | 推导、正确性依据、复杂度与完整参考实现 |

选择方向后可以填入示例问题再编辑发送，选择本身不会请求 AI。自由提问始终可用。

「回答偏好」有两组独立设置：只给提示/直接说明、简洁回答/详细展开。默认直接、简洁地回答当前问题。你在当轮问题中的明确要求优先，例如此前选择“只给提示”，随后说“现在直接告诉我怎么改”，助教应按当轮要求回答。

默认优先保留学生已有思路和实现，能局部修复就解释局部缺口。参考代码需运行、评测验证，未实测不保证 AC，自拟数据不是平台隐藏测试点。

## 代码与会话

- 每次发送读取当前编辑器代码和语言；阅读模式使用当前页保留的草稿，或最近保存的云端草稿及实际语言。其他标签页/设备未保存的内容不会自动同步。
- 正式题面、输入输出、公开样例、提示和时空限制由服务端校验题目读取权限后提供；不发送教师标准答案或隐藏测试点原文。
- 普通答疑按当前用户和题目隔离，历史保留最近十轮、24 小时有效；请求时还会按预算去掉过长的旧轮次。
- 关闭抽屉、切题或停止生成会取消请求；已收到片段标为未完成，未完成回复不作为完整回答写入服务端历史。
- 清空同时作用于服务端。若本题仍有请求处理，会提示稍后重试，不显示清空成功。
- 复盘分析指定历史提交。追问携带的前次分析仅作为用户提供的参考文字，过长时节选，不代表当前编辑器草稿。

## 比赛场景

比赛入口的题目详情页在阅读、编辑模式均不提供 AI，比赛提交也不提供 AI 复盘。后端拒绝携带比赛上下文的教学请求，并按数据库中的真实提交归属拦截复盘，包括赛后的比赛入口。

普通练习对有权查看的题目开放，不按参赛账号或题目关联比赛全局禁用。入口绕行和同题搜索不属于本功能的防作弊范围。教师命题工具保持独立。

## 接口与资源

| 接口 | 用途 |
|---|---|
| `POST /ai/ask/stream` | 答疑：problemId、studentQuestion、studentCode、language、可选 contestId 与教学偏好 |
| `POST /ai/review` | 复盘：submissionId、可选 studentQuestion/previousAnswer/contestId 与教学偏好 |
| `GET /ai/conversation?problemId=…` | 恢复当前用户本题历史 |
| `DELETE /ai/conversation?problemId=…` | 清空当前用户本题历史 |
| `GET /problem/draft/latest?problemId=…` | 当前用户本题最近保存的草稿及语言 |

`helpDirection`：AUTO、READ_PROBLEM、GET_STARTED、CHECK_APPROACH、DEBUG_CODE、EXPLAIN_CODE、TEST_CASES、OPTIMIZE、FULL_SOLUTION；`answerStyle`：DIRECT/HINT_ONLY；`detailLevel`：CONCISE/DETAILED。旧请求中的题面和 hintLevel 不再作为权威上下文或解锁依据。

SSE 沿用 message/done/app-error，收到 done 才视为完整回复。输入按字符预算控制，核心题面或代码过长时明确拒绝，检索资料允许节选并标记；字符预算不是精确 tokenizer。LEGACY/MANAGED 流式调用均实际传递配置的 max_tokens，达到上限返回 AI_OUTPUT_LIMIT，不作为完整回答保存。

ASK/REVIEW 共用用户级限频：每 60 秒最多 12 次；同用户同题的答疑、恢复和清空使用互斥租约。沿用每日 token 配额，仅成功回复消耗学生额度。

流水区分 SUCCESS、FAIL、CANCELLED、QUOTA_REJECTED、CONTEST_BLOCKED。未发送上游请求时不虚构用量；已发送且无 usage 时按已发送输入/已接收输出估算，取消后的最终费用以供应商账单为准。

开放模板键为 tutor-open、review-open；旧 tutor/review 激活版本不会覆盖新流程。新模板不插入题面/代码，不使用位置格式化占位符。学生 `/ai/hint/level` 和教师 `/ai/teacher/hint/levels` 已退役；旧 Hint 数据保留历史含义，新请求不写解锁轨迹，旧比赛全局开关与缓存配置不再生效。

## 教学质量评审

使用真实模型分别评审以下案例：正确思路的小边界错误、不成立思路的反例、复杂度不足、完全无思路、明确只要提示、首轮请求完整解答。检查是否保留已有思路、准确定位、解释充分、遵循当轮要求。模型回答正确率与课堂学习效果不能以接口测试通过替代。
