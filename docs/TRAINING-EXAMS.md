# 训练试卷

训练页提供 GESP、CSP、NOIP 和模拟套卷，可按标题搜索、分类筛选和翻页。打开试卷后点击「开始作答」，服务端开始计时；刷新或打开其他题目不会重新计时。

## 学生作答

- 答题卡可跳转题号，标记已答与未答。点击「提交客观题」会保存并即时判分，供训练订正。
- 当前浏览器会按账号、试卷和作答会话暂存选项。刷新时结合本设备草稿与服务端最后提交答案恢复；不同账号和新会话不会共用草稿。浏览器禁用或清空本地存储后，未提交草稿无法恢复。
- **本设备暂存不计分。** 手动交卷先提交当前客观题，提交失败时保留作答并提示重试。到时由服务端按已提交内容收卷；网络中断、页面关闭等情况下，尚未提交的修改不计分。
- 编程题在新标签页打开普通练习页。交卷前请确认判题完成：每题按本次会话时间范围内普通练习的最好成绩，折算到该题配置的卷内分值。比赛和虚拟赛提交不计入。尚有提交在判题时，手动交卷会提示等待；到时先锁定答题，待判题完成后自动收卷，不提前把待判题固定为零分。
- 交卷后可查看总分和已提交客观题的答案、解析。已发布试卷可再次作答，每次产生独立会话。

## 管理组卷

管理中心「训练试卷」支持标题搜索、分类、分页、复制、编辑和成绩查看。统计取每位学生最近一次已交卷记录，正确率包含未答学生；成绩明细列出各次已交卷记录并可翻页。得分率分布按卷面满分换算；等级阈值仅供参考。CSV 最多导出一万条记录。

编辑器分别配置客观题和编程题分值，顶部展示题数和分值合计。发布时要求题目合计与满分一致；草稿可先保存分值尚未对齐的内容。已经添加的题目仍需有合法题干、选项与答案，避免静默丢弃未填完的题目。

批量录入示例：

```text
SINGLE|1+1等于几？|A.1;B.2;C.3|B|5
MULTIPLE|哪些是偶数？|A.2;B.3;C.4|AC|10
JUDGE|数组下标可以从零开始。|对|5
```

每行一题；判断题答案可填 T/F、true/false、对/错。整批校验通过才导入，非法行会显示行号。多行题干、代码中的 `|` 等复杂内容请使用逐题编辑。

## 已有作答记录的试卷

已有任意作答记录后，题目内容、顺序、分值、时长和满分被锁定，避免历史成绩丢失或含义改变。标题、描述、分类、等级与发布状态仍可维护。需要重新编排时先复制为新草稿。

已有作答记录的试卷不能删除，可取消发布。取消发布后不再提供新开考入口，已有本人作答记录的学生仍可通过原链接续答或复盘。

旧卷若把编程题分值配置为 0，系统会按 0 分计入；不会自动把它解释为 100 分，也不会重写历史成绩。请核对旧卷，必要时复制并重新配置分值。
